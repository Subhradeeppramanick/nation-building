# Indian Army's Role in Nation Building

A small one-page website about the Indian Army's contributions to national life beyond guarding the borders: disaster relief, Operation Sadbhavana, border roads and infrastructure, education and youth, and veterans' welfare.

Every section links to the public official source it draws from (indianarmy.nic.in, pib.gov.in, bro.gov.in).

**This is a personal project created for learning and awareness. It is not an official website of the Indian Army or the Government of India, and no institutional endorsement is implied.**

The whole site is a single file: `index.html`. Open it in any browser, or host it free with GitHub Pages.
